# Check-up Manager

**[▶ Ζωντανό demo](https://checkup-manager-6jph5zwvlekqwzhsxhqzc5.streamlit.app/)** 
Εργαλείο διαχείρισης του περιοδικού ιατρικού ελέγχου (check-up) των
εργαζομένων μιας βιομηχανικής μονάδας.

Αντικαθιστά μια χειροκίνητη διαδικασία: υπολογισμό του ποιος οφείλει
εξετάσεις κάθε έτος, επιλογή προγράμματος ανά εργαζόμενο και συμπλήρωση
με το χέρι πάνω από 1.000 εντύπων παραπομπής τον χρόνο.

## Τι κάνει

- **Προγραμματισμός** — εφαρμόζει τον κανόνα συχνότητας (κάτω των 40 κάθε
  3 χρόνια, 40-49 κάθε 2, από 50 κάθε χρόνο) και βγάζει ποιοι οφείλουν
  έλεγχο στο επιλεγμένο έτος, με αιτιολογία για κάθε απόφαση.
- **Ανάθεση προγράμματος** — τρεις μεταβλητές (φύλο, ηλικία, χώρος
  εργασίας) καθορίζουν ένα από 10 προγράμματα και τα αντίστοιχα
  παραπεμπτικά. Λαμβάνει υπόψη τη λίστα εξαιρέσεων ακοομετρίας.
- **Κοστολόγηση** — εκτίμηση κόστους ανά πρόγραμμα και συνολικά, πριν
  ξεκινήσει η διαδικασία.
- **Παραγωγή εντύπων** — ένα PDF με συνοδευτική κατάσταση, τις εντολές
  εκτέλεσης συμπληρωμένες (ονοματεπώνυμο, Α.Μ., εξετάσεις) και έντυπο
  ενημέρωσης/συγκατάθεσης ΓΚΠΔ ανά εργαζόμενο.

## Εκτέλεση

```bash
pip install -r requirements.txt
streamlit run app.py
```

Η εφαρμογή ανοίγει με **συνθετικά δεδομένα επίδειξης** (`demo_data.xlsx`,
263 πλασματικοί εργαζόμενοι). Μπορείτε να ανεβάσετε δικό σας αρχείο από
το πλαϊνό μενού.

## Δομή

| Αρχείο | Ρόλος |
|---|---|
| `rules.py` | Κανόνες ανάθεσης προγράμματος και παραπεμπτικών |
| `schedule.py` | Κανόνας συχνότητας ανά ηλικιακή ζώνη |
| `costs.py` | Τιμοκατάλογος και κοστολόγηση |
| `documents.py` | Παραγωγή PDF (εντολές, συγκατάθεση, κατάσταση) |
| `app.py` | Διεπαφή χρήστη (Streamlit) |
| `make_demo_data.py` | Παραγωγή συνθετικών δεδομένων |
| `verify.py` | Έλεγχος συνέπειας κανόνων και μοντέλου κόστους |

## Προστασία δεδομένων

Το αποθετήριο δεν περιέχει κανένα πραγματικό δεδομένο:

- **Εργαζόμενοι** — πλασματικοί, παράγονται από το `make_demo_data.py`
  με σταθερό seed. Ονόματα, αριθμοί μητρώου, τμήματα και ημερομηνίες
  δεν αντιστοιχούν σε υπαρκτά πρόσωπα.
- **Στοιχεία οργανισμού** — placeholders στο `config.py`. Τα πραγματικά
  ορίζονται σε `config_local.py`, που εξαιρείται από το git.
- **Τιμές εξετάσεων** — ενδεικτικές, όχι συμβατικές τιμές οργανισμού.

Τα δεδομένα υγείας εργαζομένων αποτελούν ειδική κατηγορία δεδομένων κατά
το άρθρο 9 ΓΚΠΔ. Πριν από οποιαδήποτε παραγωγική χρήση απαιτείται έγκριση
του Υπευθύνου Προστασίας Δεδομένων του οργανισμού και εκτέλεση σε
υποδομή του οργανισμού - ποτέ σε δημόσια φιλοξενία.

Τα δεδομένα υγείας εργαζομένων αποτελούν ειδική κατηγορία δεδομένων κατά
τον ΓΚΠΔ. Πριν από οποιαδήποτε παραγωγική χρήση απαιτείται έγκριση του
Υπευθύνου Προστασίας Δεδομένων του οργανισμού.
